# Atividade-de-Laboratório-Controle-de-Fluxo-Avançado-em-Kotlin

Repositório criado para a resolução da Atividade de Laboratório sobre estruturas de repetição, condicionais e manipulação do fluxo de execução em Kotlin.

## Sobre o Projeto
Este projeto contém a implementação de 8 exercícios práticos focados no controle de fluxo da linguagem Kotlin. O objetivo principal é dominar a lógica algorítmica de laços de repetição (`for`, `while`) e os comandos de interrupção e salto (`break`, `continue`).

## Exercícios Resolvidos
1. **O Filtro de Vogais:** Uso de `continue` para saltar caracteres específicos.
2. **O Primeiro Múltiplo Comum:** Controle de laço infinito `while(true)` com `break`.
3. **Somador com Limite de Carga:** Combinação de `continue` para pular múltiplos de 10 e `break` para teto de soma.
4. **Simulador de Caixa Eletrônico:** Validação condicional de saldo antes de operações.
5. **Detecção de Números Primos:** Otimização de processamento abortando laços desnecessários.
6. **O Menu Teimoso:** Retorno instantâneo ao início do menu usando `continue`.
7. **Pula-Obstáculos Numérico:** Identificação de dígitos usando o resto da divisão matemática (`% 10`).
8. **Cofre com Bloqueio Progressivo:** Aplicação do `break` com dois propósitos distintos (sucesso de login e punição por limite de tentativas).

## Tecnologias e Conceitos
* **Linguagem:** Kotlin
* **Ferramentas:** VS Code
* **Conceitos aplicados:** Variáveis (mutáveis e imutáveis), Estruturas Condicionais, Operadores Lógicos/Matemáticos e Fluxo de Execução.

## Como Executar
1. Faça o clone deste repositório.
2. Abra a pasta do projeto na sua IDE.
3. Navegue até os arquivos e execute a função `main()` de cada exercício individualmente para testar as saídas no terminal.
